# نقية — NQiya

إضافة كروم تساعدك تراجع تعليقاتك ومنشوراتك القديمة على فيسبوك قبل سنة تختارها، وتاخذ نسخة احتياطية منها.

**المرحلة الأولى فقط: فحص + معاينة + نسخة احتياطية. ما فيه أي كود حذف، ولا أي كود يضغط على قوائم فيسبوك.**

---

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `manifest.json` | إعدادات الإضافة (Manifest V3) |
| `background.js` | Service worker: الإعدادات الافتراضية وحفظ حالة الفحص |
| `content.js` | فحص صفحة «سجل النشاط»: selectors، تحميل تلقائي، تحليل التواريخ |
| `popup.html` | واجهة الإضافة (عربي، RTL) |
| `popup.js` | منطق الواجهة: بدء/إيقاف الفحص، عرض النتائج، النسخة الاحتياطية، نسخ HTML |
| `popup.css` | التنسيق (أبيض + أخضر `#00a651`) |

---

## كيف تستخدمها

1. ثبّت الإضافة (الخطوات في آخر الملف).
2. افتح فيسبوك، وافتح **سجل النشاط** يدوياً:
   - من ملفك الشخصي → زر «⋯» → **سجل النشاط**
   - أو الرابط: `https://www.facebook.com/me/allactivity`
3. اضغط أيقونة «نقية» في شريط الإضافات.
4. اختر السنة في «اعرض كل شيء قبل سنة:» (2015–2019)، وحدّد «تعليقاتي» و/أو «منشوراتي».
5. اضغط **افحص حسابي الآن**. الإضافة تنزل الصفحة تلقائياً بفواصل عشوائية (1.5–3 ثانية) لحد 300 عنصر.
6. تشوف النتائج في القائمة، والعداد يقول «لقينا N عنصر».
7. اضغط **تحميل نسخة احتياطية (JSON)** لتنزيل `nqiya-backup-DD-MM-YYYY.json`.

زر **إيقاف** يوقف الفحص ويحفظ اللي انلقى لحد تلك اللحظة.
زر **نسخ HTML للتشخيص** ينسخ HTML لأول 3 عناصر من سجل النشاط للحافظة (يساعد في تصحيح الـ selectors).

### شكل النسخة الاحتياطية

```json
[
  {
    "text": "نص التعليق أو المنشور…",
    "date": "2018-03-12",
    "link": "https://www.facebook.com/permalink.php?story_fbid=..."
  }
]
```

`date` دايماً بصيغة `YYYY-MM-DD`، والعناصر مرتبة من الأحدث للأقدم.

---

## قواعد الفحص

- **يشتغل فقط على صفحة «سجل النشاط»**. إذا الصفحة مو سجل نشاط، الإضافة تعرض رسالة عربية تطلب منك تفتحه — **ما تنتقل تلقائياً** لأي صفحة.
- **ما يعتمد على تخمين التاريخ**: لو التاريخ ما انقرأ بيقين، العنصر يتعلّم «تاريخ غير معروف» **ويُستثنى** من النتائج.
  - يدعم أسماء الأشهر بالعربي (يناير… ديسمبر، وكذلك كانون الثاني/شباط/آذار/نيسان/أيار/حزيران/تموز/آب/أيلول/تشرين الأول/تشرين الثاني/كانون الأول)، بالفرنسي (janvier…décembre)، وبالإنجليزي (January…December + الاختصارات).
  - يدعم الأرقام العربية-الهندية (٠١٢٣…) والفارسية (۰۱۲…).
  - يقبل `YYYY-MM-DD`، ويقبل `DD/MM/YYYY` أو `MM/DD/YYYY` **فقط** إذا كان أحد الرقمين أكبر من 12. إذا الاثنين ≤ 12 (غامض) → تاريخ غير معروف ولا يُخمَّن.
  - يرفض السنوات ذات الرقمين (مثل `12/03/18`) لأنها غامضة.
- **حد أقصى 300 عنصر** في الفحص الواحد، ويتوقف تلقائياً إذا نزل 4 مرات بدون عناصر جديدة.
- النتائج تُحفظ في `chrome.storage.local` وتُرسل للواجهة عبر `chrome.runtime.sendMessage`، فتقدر تسكّر النافذة والفحص يكمل.
- ما فيه أي كود يحذف أو يضغط على قوائم فيسبوك (لا حذف، لا «⋯»، لا أزرار).

## تعديل الـ selectors

كل ما يتعلق بـ DOM فيسبوك موجود في **كائن واحد** في أعلى `content.js`:

```js
const SELECTORS = {
  activityPage: { urlHints, headingSelectors, headingTexts },
  itemContainers: [...],        // حاويات العنصر، تُجرّب بالترتيب
  itemLinkAnchors: [...],       // روابط دائمة (permalink) — تُستخدم كخطة بديلة
  textCandidates: [...],        // عناصر نص العنصر
  dateCandidates: [...],        // عناصر التاريخ (title / aria-label / النص)
  scrollContainers: [...],      // الحاويات القابلة للتمرير
  anchorClimbLevels: 8,
  firstItemsForDebug: 3
};
```

إذا فيسبوك غيّر التصميم:

1. افتح سجل النشاط، واضغط **نسخ HTML للتشخيص**، والصق HTML في محرر.
2. شوف كلاسات/خصائص حاوية العنصر، وأضف selector جديد في بداية `itemContainers` (الأولوية للأول).
3. إذا الحاوية مو واضحة، خلّي `itemLinkAnchors` تتكفل — الكود يصعد من رابط العنصر لحد 8 مستويات فوقه ويلاقي الحاوية اللي فيها تاريخ.
4. حدّث `textCandidates` / `dateCandidates` إذا النص أو التاريخ ما انقرأ.

للتجربة السريعة من Console الصفحة: `__nqiyaParseDate('12 مارس 2018')`.

## الخصوصية

- ما فيه أي طلب شبكة خارجي، ولا API خارجي، ولا مكتبات.
- كل شي يصير محلياً في متصفحك: `chrome.storage.local` والملف اللي تنزّله بنفسك.
- الصلاحيات: `storage` (حفظ النتائج والإعدادات)، `activeTab` + `scripting` (تشغيل الفحص في التبويب الحالي)، و`*://*.facebook.com/*` (قراءة سجل النشاط).

---

## حدود معروفة

- فيسبوك يغيّر الـ DOM باستمرار، فممكن تحتاج تحديث الـ selectors.
- التمييز بين «تعليق» و«منشور» يعتمد على شكل الرابط (`comment_id` = تعليق، وإلا منشور). العناصر اللي ما نقدر نحدد نوعها تُحسب ضمن الفلتر المختار.
- الفحص يحتاج الصفحة مفتوحة وقدامك؛ ما يشتغل في الخلفية بدون تبويب.
- التحميل يتم عبر Blob من النافذة المنبثقة؛ بعض إعدادات كروم الصارمة قد تطلب تأكيد التحميل.

## التثبيت في كروم

1. افتح `chrome://extensions`.
2. شغّل **وضع المطوّر / Developer mode** (زر في أعلى اليمين).
3. اضغط **Load unpacked / تحميل غير مضغوط**.
4. اختر المجلد اللي فيه `manifest.json`.
5. ثبّت الإضافة، وثبّت أيقونتها في شريط الأدوات (Pin).
6. افتح فيسبوك → سجل النشاط → اضغط الأيقونة → «افحص حسابي الآن».

بعد أي تعديل على الملفات: ارجع لـ `chrome://extensions` واضغط **⟳ تحديث** على الإضافة، وحدّث صفحة فيسبوك.

## المرحلة القادمة (غير منفّذة هنا)

المراجعة عنصر عنصر، وتحديد اللي تبي تحذفه، ثم الحذف — كل هذا **مو موجود** في هذه النسخة عمداً. أي كود حذف يُضاف في مرحلة منفصلة وبموافقة صريحة من المستخدم لكل عنصر.
